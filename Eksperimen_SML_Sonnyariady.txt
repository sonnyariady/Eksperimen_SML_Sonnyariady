Repository Eksperimen Kriteria 1:

Dataset:
Indonesian Food Classification
https://www.kaggle.com/datasets/rizkyyk/dataset-food-classification

Repository dibuat public sesuai ketentuan submission.

Isi repository eksperimen mencakup:

1. Data Loading
- Load dataset image makanan Indonesia
- Split train, validation, dan testing

2. Exploratory Data Analysis (EDA)
- Distribusi kelas
- Visualisasi sample gambar
- Analisis jumlah data

3. Data Preprocessing
- Resize image
- Normalisasi image
- Label encoding
- Data augmentation

4. Model Training
- CNN TensorFlow/Keras
- Hyperparameter tuning
- Evaluasi model

5. MLflow Experiment Tracking
- Logging metrics
- Logging parameter
- Logging model artifact

6. Automation Script
- automate_Sonnyariady.py
- preprocessing otomatis dataset

Struktur repository eksperimen:

- notebook_eksperimen.ipynb
- automate_Sonnyariady.py
- requirements.txt
- README.md
